# Study Tracker Dashboard

A full-stack study tracker built with Flask, HTML, CSS, and JavaScript.

## Features

- Add study tasks
- Delete tasks
- Mark tasks as completed
- Persistent task saving using localStorage
- Dynamic task rendering
- Responsive and modern UI styling

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## How To Run

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate into the project folder

```bash
cd study-tracker
```

3. Run the Flask server

```bash
py app.py
```

4. Open your browser and visit

```text
http://127.0.0.1:5000
```
